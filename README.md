# Python Chess Engine

A chess engine written from scratch in pure Python.

## Features

- Pawn movement and captures
- Knight movement
- Bishop movement
- Rook movement
- Queen movement
- King movement
- Turn management
- Check detection
- Checkmate detection

## Example

```text
e2 e4
e7 e5
g1 f3
```
